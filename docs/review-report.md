# Ark Lens v1 리뷰 보고

> 대상: 로컬 커밋 `60b6019` (Codex 구현) · 리뷰일 2026-11-25
> 기준: `docs/ui-design.md`, CHARACTERS·ARMORIES 가이드 §4(Tooltip)·§5(오류·캐싱)
> 실제 API 키와 실호출은 사용하지 않았습니다. 검증에는 MSW, 합성 픽스처, 개발 데모를 썼습니다.

## 요약

구현은 설계를 충실히 따릅니다. 상태 매핑(401/404/200+null/프로필 누락/429/503/network/server), `encodeURIComponent`, 리터럴 `+` 필터, 키를 헤더로만 보내는 방식, 평문 렌더링, `dangerouslySetInnerHTML` lint 금지, 블록 타입과 제목으로 찾는 Tooltip 파서가 모두 맞게 되어 있었습니다. 발견한 문제는 주로 운영 데이터에서만 드러나는 것들입니다(CSP 이미지 호스트, 저장소 용량, 네거티브 캐시). 각 문제는 고쳤고 테스트를 추가했습니다.

## 확인했지만 바꾸지 않은 것

- **filters·인코딩**: `ARMORY_FILTERS`를 문자열로 직접 붙이고, 이름은 `trim()` 뒤에 `encodeURIComponent`로 처리합니다. 맞습니다.
- **상태 처리**: 401이면 키를 지우지 않고 `rejected`로 바꿉니다. 200+null과 `ArmoryProfile == null`은 not-found입니다. 429는 Reset 헤더나 가장 오래된 요청+60초 뒤에 1회만 자동 재시도합니다. 503은 5분 쿨다운입니다. 캐시가 있으면 배너로만 알립니다. fetch `TypeError`는 network, abort는 그대로 전파합니다. 모두 맞습니다.
- **레이트 게이트**: 60초 슬라이딩 윈도이고, 잔여 5 이하면 차단합니다. `X-RateLimit-*`가 읽히면 그 값을 우선합니다(Reset을 epoch 초/ms/상대 초 모두로 해석). 설계는 대기열에 넣는 방식이지만 구현은 즉시 rate-limited 상태로 바꾼 뒤 카운트다운하고 자동 재시도합니다. 사용자에게 보이는 결과는 같다고 판단해 그대로 두었습니다.
- **Tooltip 파서**: `Element_XXX` 인덱스를 하드코딩하지 않습니다. 모든 정규식에 `i` 플래그가 있고, `#?` HEX와 팔찌 `<img>` 마커로 여러 줄 옵션을 묶는 것도 맞습니다.
- **보안**: 키는 `authorization` 헤더로만 보냅니다(`credentials: omit`, `redirect: error`). 오류 상세에서는 키를 가립니다. 소스·테스트·픽스처에서 JWT 형태(base64url 세 부분) 문자열을 grep한 결과 0건입니다. 운영 번들에 `demo.fixture`, 데모 캐릭터명, 테스트 토큰이 없는 것을 `dist/` grep으로 확인했습니다. `dangerouslySetInnerHTML`/`innerHTML`도 0건입니다. 외부 링크에는 모두 `noopener noreferrer`, `no-referrer`가 붙어 있습니다.
- **접근성**: 탭에 `role=tablist/tab`과 방향키·Home·End 이동이 있습니다. 드로어는 `<dialog>.showModal`이라 기본으로 포커스가 갇히고, Esc로 닫으며, 닫으면 포커스가 돌아옵니다. 알림은 `role=alert`/`status`, 스켈레톤은 300ms 지연과 `aria-busy`입니다.

## 제안 (큰 변경이라 손대지 않음)

1. **연마 효과 중/하 판별**: 지금은 `#FE9600`만 "상"으로 보고, 중/하는 `[중]`/`[하]`가 명시된 경우에만 표시합니다. 가이드 §4에서도 중/하 색은 미확인입니다. 실제 응답을 받으면 색 매핑표를 추가하세요.
2. **CSP 이미지 호스트 실측**: 이번에 `img.lostark.co.kr`를 추가한 것은 가이드 샘플을 근거로 한 것입니다. 실키로 아이콘과 초상화 호스트를 확인해 README "키로 확인할 것"을 마무리하세요.
3. **siblings 원정대 공유 캐시**(가이드 §6.2): 같은 원정대의 다른 캐릭터에서 드로어를 열면 지금은 다시 호출합니다. 원정대 멤버 이름으로 역인덱싱하면 호출 1회로 줄일 수 있습니다.
4. **503 서킷 브레이커**(가이드 §5.2): 연속 503이 오면 다른 캐릭터 검색도 잠시 막는 전역 차단. 지금 쿨다운은 화면 안의 "상태 확인" 버튼에만 걸려 있습니다.
5. **파일 구조**: 설계 §8의 `api/ storage/ features/` 디렉터리 구조 대신 `src/` 아래 파일 몇 개로 평평하게 되어 있습니다(`sections.tsx` 640줄). 동작에는 문제가 없지만 v2에서 탭을 늘리기 전에 나누는 것이 좋습니다.
