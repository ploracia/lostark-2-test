## 3. 엔진·배지 점검 결과

- 순수성: `computeTransfer`는 입력과 overrides를 바꾸지 않고, 같은 입력에는 같은 결과를 냅니다(테스트 추가).
- 경계값: 표1 경계(50 / 50.5 / 100 / 100.01 / 1675 / 1676 / 1785 / 1786 / 1790 / 1791 / 1800 / 1800.01), 품질 67/66, 빈 장비(16부위 모두 계산 불가, 평균 계산 불가), 장신구 null 필드(tier, quality, options)를 모두 테스트했습니다.
- 추가 API 요청: 0회입니다. 이관 탭은 이미 받은 Armory 응답만 씁니다. 기존 MSW 테스트가 탭 전환 20회 뒤에도 요청 1회, 최근 검색 기록 1회임을 확인합니다.
- 배지: 숫자는 `Est` 타입을 거쳐서만 나옵니다. 미확인(`kind: "none"`)은 숫자 필드가 없어서 숫자로 렌더링될 수 없습니다. 이번에 고친 #2·#3·#4로 "공식 확정"이 붙는 범위가 공지에 근거가 있는 값으로 줄었습니다.

## 4. 보안·접근성·반응형·회귀

- 보안: 외부 링크는 모두 `noopener noreferrer`입니다. `dangerouslySetInnerHTML`은 없습니다. 키는 이관 탭에서 쓰지 않습니다.
- 접근성: 탭은 `role=tab`·`tabpanel`이고 방향키·Home·End·Space가 동작합니다. 범위 값은 `aria-label="최소 n, 최대 m"`으로 읽히고, 입력 오류는 `aria-invalid`와 `aria-describedby`로 연결됩니다.
- 반응형: 390px 라이트/다크와 1280px에서 가로 스크롤이 없습니다(scrollWidth 390 = innerWidth 390).
- 회귀: 현재 탭, 최근 검색 5개 기록, 각인 아이콘 테스트가 모두 통과합니다.

## 5. 추가 요청: 카드 이름 위치

- `CardSet`이 이제 카드 그림 틀(`.tcard-art`), 각성 점, 이름 순으로 그립니다. 이름은 그림 밖, 카드 아래에 표시됩니다. 각성 점은 이름 바로 위에 있어 그림을 가리지 않습니다.
