Open API 키 설정

로스트아크 Open API 키(JWT)를 넣으면 이 브라우저에서 바로 공식 API를 호출합니다. 키는 서버로 보내지 않고, Smilegate API 서버로만 전송됩니다.
"bearer " 접두사 없이 토큰만 붙여넣으세요. 앞뒤 공백, 중괄호/꺾쇠는 자동으로 제거됩니다.
✓ 검증 성공. 키가 정상입니다. 2026-11-25 16:04 저장됨 · 마지막 4자리 …x7Qa
✕ 401 · 키가 거부되었습니다. 토큰이 잘렸거나 삭제된 클라이언트의 키일 수 있습니다.

키 발급 방법

  1. 로스트아크 Open API 개발자 포털 ↗에 스토브 계정으로 로그인합니다.
  2. GET ACCESS TO LOSTARK API 또는 MY CLIENTS에서 클라이언트를 만듭니다. 계정당 5개까지 만들 수 있습니다.
  3. 발급된 API KEY(JWT)를 복사해 위 칸에 붙여넣습니다. 키는 만료되지 않고, 클라이언트를 지우면 무효가 됩니다.

보안 안내 꼭 읽어 주세요

⚠ 키는 암호화되지 않은 상태로 브라우저 저장소에 보관됩니다. 같은 기기의 다른 사용자, 브라우저 확장 프로그램, 이 사이트에서 실행되는 스크립트는 키를 읽을 수 있습니다.
  • 공용 PC에서는 "이번 탭에서만 사용"을 고르고, 다 쓰면 키 삭제를 누르세요.
  • 키가 유출되었다면 포털에서 해당 클라이언트를 삭제하고 새 키를 발급하세요.
  • 요청 한도는 클라이언트당 분당 100회이며, 이 앱은 한 번 검색할 때 1~2회를 씁니다.
